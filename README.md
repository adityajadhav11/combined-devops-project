# Combined DevOps Projects

This repository contains two separate projects:

## 1. AJ Electronics Website
- A modern, minimalist website for showcasing electronics products.
- Located in the `aj-electronics-site/` folder.

### How to deploy:
- This website is deployed to AWS S3.

## 2. CI/CD DevOps Project
- A DevOps pipeline for automating deployment and infrastructure management.
- Located in the `cicd-devops-project/` folder.

### How to deploy:
- This project uses CI/CD pipelines for automating deployment.
